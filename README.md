# Nuxt 4

This is a Nuxt 4 project (migrated from the Vue 3 + Vite starter template).

## Setup

```bash
npm install
```

## Development Server

```bash
npm run dev
```

Start the development server on `http://localhost:3000`.

## Production

```bash
npm run build
npm run preview
```

For a static site:

```bash
npm run generate
```

Learn more about Nuxt in the [Nuxt documentation](https://nuxt.com/docs).
